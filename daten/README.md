# daten/

`trainer.json` wird gebaut, nicht von Hand gepflegt.

    python3 vokabeln/_trainer_daten.py

Quellen und wie die Reihenfolge zustande kommt, stehen im Kopf dieses Skripts.

Die Häufigkeitsliste `vokabeln/_haeufigkeit.txt` stammt aus dem Projekt
FrequencyWords von Hermit Dave (OpenSubtitles 2018, Liste `pt`, also
europäisches Portugiesisch), veröffentlicht unter CC BY-SA 4.0.
Sie wird nur beim Bauen gelesen und nicht an das Handy ausgeliefert.
